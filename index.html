01 · Flagship Project

RAG Q&A System

PythonLangChainChromaDB OpenAI EmbeddingsRagasStreamlitBM25 + Reranking

An incremental Retrieval-Augmented Generation pipeline that ingests PDF/Markdown/text documents, retrieves context via hybrid semantic + keyword search, and generates grounded answers — with a built-in evaluation harness to measure whether those answers are actually trustworthy.

What makes it stand out: most RAG demos stop at "it returns an answer." This one goes further with a Ragas-based benchmark suite (scoring Faithfulness & Answer Relevancy) to quantitatively verify the system is actually trustworthy — evaluation, not just generation.
  • Ingests PDF/Markdown/text documents with semantic chunking (RecursiveCharacterTextSplitter) and embeds them with OpenAI's text-embedding-3-small model into a persisted Chroma store, retrieving top-k matches ranked by distance score alongside source metadata for traceability
  • Combines semantic search + BM25 keyword search via Reciprocal Rank Fusion, then applies cross-encoder reranking to sharpen the final context set before generation
  • Grounds generation (gpt-4o-mini) strictly in retrieved context with prompt constraints forcing an explicit "I don't know" fallback — reducing hallucination risk
  • Adds conversational memory that auto-rephrases ambiguous follow-ups before re-querying the vector store
  • Ships an interactive Streamlit dashboard with on-the-fly document upload, adjustable chunking, and retrieval audit logs with relevance scores
  • Runs a batch benchmark suite using Ragas with GPT-4o-mini as judge to quantitatively track answer quality over time

02 · Real-time AI Workflow

Perplexity 2.0 — Conversational AI Search Assistant

FastAPILangGraphTavily API Server-Sent EventsNext.js / ReactGPT-4o

A full-stack, Perplexity-style AI chat app that decides in real time whether to answer directly or search the live web, then streams the response back token-by-token with live status updates — the same kind of multi-stage, low-latency AI workflow orchestration used in voice/chat product pipelines.

What makes it stand out: a full client/server split (Next.js ↔ FastAPI) with real-time token streaming and agent decision-making — a working example of shipping an AI feature as a complete product, not just a notebook demo.
  • Modeled the agent as a LangGraph StateGraph with conditional edges, routing between a direct-answer node and a web-search tool node based on the LLM's own decision
  • Streams responses token-by-token via Server-Sent Events, surfacing live status across the search → read → write stages of the agent loop
  • Injects live web search results (Tavily API) back into context before generation for up-to-date answers
  • Maintains multi-turn conversation state through the graph so the agent resolves context-dependent follow-ups

03 · Agentic Tool-Calling

LLM-Powered File Assistant

PythonLangChainFunction Calling Typed Tool Schemas

An agentic assistant that lets users query and manage local files using plain natural language — the LLM decides which tool to call and with what arguments, rather than the user writing commands.

What makes it stand out: a small, self-contained study in prompt-to-action reliability — getting an LLM to reliably choose the right tool, produce valid arguments, and chain calls safely.
  • Uses LangChain tool-calling (function calling) to translate natural-language intent into executable file operations
  • Exposes each file operation (search, read, manage) as a discrete LangChain Tool with a typed input schema
  • Lets the agent chain multiple tool calls per request, parsing intent step-by-step rather than in one shot
